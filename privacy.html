SOSYAL Bot — Privacy Policy

Last updated: 14 November 2026

SOSYAL Bot ("the app") is a personal desktop tool used by a single YouTube channel owner on their own computer. It uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

1. Google user data the app accesses

After the channel owner signs in with Google (OAuth 2.0) and grants permission, the app accesses:

  • Channel information and statistics of the signed-in user's own channel (channel ID, title, subscriber, view and video counts).
  • The user's own videos and their public statistics (title, publish time, duration, view, like and comment counts).
  • Comments on the user's own videos (comment text, author display name, time) so that reply drafts can be prepared.
  • Video upload: the app uploads only video files that the user approved, with the metadata the user approved, and sets the thumbnail image that was generated together with that video.
  • Optionally, if the user grants the extra permission, YouTube Analytics reports for the user's own channel (watch time, audience retention, traffic sources).
  • Public YouTube data (popular videos, search results) to suggest content topics.

OAuth scopes: youtube.upload, youtube.force-ssl, and optionally yt-analytics.readonly.

2. How the data is used

The data is used only to provide the app's features to the signed-in user: uploading the user's approved videos, preparing comment reply drafts that are posted only after the user approves them, and showing the user statistics about their own channel. The data is not used for advertising, is not sold, and is not used to train AI models.

3. Storage, sharing and security

  • All data is stored only on the user's own computer (local files). The app has no servers and the developer does not receive any of the data.
  • The OAuth token is stored locally on that computer and is never shared.
  • Data is not shared with, transferred to or disclosed to any third party.
  • The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Retention and deletion

Stored statistics and comment drafts remain on the user's computer until the user deletes them. The user can delete all stored data at any time by deleting the app's local data folder, or by running the app's sign-out command, which removes the stored token. YouTube API data that is kept is refreshed or deleted at least every 30 days.

5. Revoking access

You can revoke the app's access to your Google account at any time on the Google security settings page: https://myaccount.google.com/permissions. After revocation the app can no longer access your data.

6. Cookies and device information

The app does not use cookies and does not store or read information on users' devices or browsers other than the local files described above. This website does not use cookies or tracking.
